## 简介

青鸾记账支持日常收支记录、分类统计、多币种和本地备份。无需注册账号，无广告；账单、票据和个人资料默认保存在应用的本地私有目录。联网权限用于用户主动发起的 WebDAV 备份同步。

当前版本：**v1.1.0**。版本说明见 [更新日志](CHANGELOG.md)。

## 功能

### 记账与管理

- 记录收入、支出、日期、时间、备注及最多8张票据图片，支持逐张预览和移除，兼容旧单张记录。
- 自定义收支分类与图标，长按拖动调整分类顺序；支持保留分类的独立账单迁移。
- 点击账单直接编辑，左滑确认删除，并可撤销删除操作。
- 长按账单直接在明细页勾选，顶部悬浮操作栏提供编辑、导出、删除与全选，不推动列表或改变卡片尺寸，批量修改分类、备注和标签，或删除、导出所选账单。
- 按月份、日期范围、收支类型、分类及关键词筛选账单。
- 支持滚动渐进显示；宽屏内容限宽，横屏表单可滚动，大字号账单金额独立换行。系统支持时使用预测性返回，取消返回手势不会退出多选。

### 标签与存储管理

- “我的 → 分类与标签 → 标签管理”可创建、改名、删除标签模板，并选择所属收支分类；同一分类下名称不能重复。
- 选完记账分类后可多选对应标签；模板变更不改写历史账单，原标签文字继续随账单保存、搜索和导出。
- 分类选择支持所有、支出、收入；高级搜索支持标签任一/全部匹配，“账单管理 → 标签统计”按月分析，多标签总览每笔只计一次。
- 列表显示可独立开关标签显示，不影响保存、搜索和导出。
- 标签较多时提供按需加载的完整选择列表；单个名称最多24字、模板最多1000个，每笔账单标签文字总长不超过300字。
- “数据管理 → 存储空间管理”按文件统计占用，提供缓存、日志、回收站、恢复前副本清理和数据库整理；票据和回收站内容已包含在数据库中，不重复计入总量。
- 清理不删除正常账单、头像、分类、标签模板、设置或连接凭据；缓存清理不跟随符号链接。

### 搜索、回收站与周期账单

- 高级搜索支持日期范围或全部日期、金额范围、币种、分类、关键词及有无票据；可保存最多10组常用筛选。
- 金额条件按每条账单的原币金额筛选，不进行汇率换算。
- 删除账单后移入回收站，保留备注、旧标签和票据，可恢复或确认后彻底删除；原分类已删除时可重建相应分类。
- 回收站默认保留30天，可选7天、90天或永久；打开应用时清理超期记录，缩短期限前确认清理。
- 周期账单支持按天、周、月、年设置间隔，可编辑、暂停、确认入账或跳过本期。月末和闰年日期会适配，连续点击确认不会重复生成同一期账单。
- 周期项目在打开应用时显示待确认状态，**需要用户确认入账**，不使用后台自动入账或系统定时通知。
- 在“我的 → 其他设置”开启桌面快捷记账后，长按桌面应用图标可记支出或记收入；默认关闭并保存在本机，不提供桌面小组件。关闭时移除快捷入口并禁用已固定的对应快捷方式。

### 分期账单

- “我的 → 账单管理 → 分期账单”设置本金、总手续费、期数和首期日期，按月生成待确认项目。
- 金额按最小货币单位精确分摊，所有期数之和等于本金加手续费；支持月末日期、暂停和完成进度。
- 到期后由用户确认入账，不自动扣款。删除生成账单不会回退已确认进度；删除计划保留已生成账单。
- 已确认首期后不允许修改本金、手续费、币种和总期数，避免历史分摊发生变化。

### 预算与默认币种

- “我的 → 账单管理 → 预算管理”支持分币种的每月总预算和分类预算，显示已用、剩余、进度及超支。
- 预算按月份独立保存，修改和停用只影响选中月份；旧版重复方案保留为默认值，月度覆盖不会修改其他月份。不同币种分别统计，分类预算不与总预算相加。
- 支出计入预算，收入、回收站中账单和未确认的周期草稿不计入；不提供系统超支通知。
- “个性化 → 主币种”决定新账单、桌面快捷记账、周期及预算草稿的默认币种，不转换既有记录。
- 明细搜索左侧可临时隐藏/显示金额，不覆盖原有隐藏设置，不进入备份。

### 统计与多币种

- 提供月度、年度和全部记录的收入、支出、结余统计。
- 展示收支趋势、分类排行、圆环占比、日历及年度报告。
- 支持 178 种内置 ISO 4217 币种及对应金额精度，优先显示实际常用币种。币种列表使用系统 Unicode 地区旗帜；多国共用、无对应地区或系统不支持时显示中性图标。
- “全部”视图的平均值按总金额除以有账单的不同日期数计算。
- 不同币种分别统计，不提供汇率换算，也不直接合计不同币种。
- 可设置默认统计周期、类型、图表，并记住统计筛选。

### 外观与操作

- 默认跟随系统外观，支持浅色、深色及纯黑深色模式；深色图标容器保留清晰的主题底色。
- 提供多种主题配色；Android 12 及以上支持系统动态配色。
- 可调整字号、列表密度，以及时间、备注和金额的显示方式；自定义字号提供75%–160%滑块、精确输入与预览。
- 支持悬浮记账按钮、轻量页面转场和透明模糊底栏；启动交接采用约180ms淡出与轻微缩放，关闭灵动效果或系统动画后即时切换。
- 可配置局部动画、触觉反馈的强度及触发场景；关闭灵动效果时页面即时切换。
- 明细条目的时间显示在备注之前。
- 支持本地昵称、头像及圆形裁剪。

### 导入、导出与保护

- **JSON**：完整备份与恢复，也支持追加导入或替换指定范围的账单。
- **CSV / XLSX**：导入、导出本应用表头的账单表格，可选择备注、标签和票据列；XLSX支持常见Excel日期与时间格式。较大票据存入辅助工作表，请保留该表以便还原。
- **加密备份（`.qlb`）**：使用密码保护 JSON 备份，采用 AES-256-GCM。
- 导入前预览总数、有效、新增、重复、错误与范围外数量，并查看样例及错误行原因；CSV含错误行时需明确同意仅导入有效行，结构错误或无效完整备份会直接拒绝。
- 导出支持全部、当前明细筛选、指定日期或多选账单，可设置文件名并选择保存位置。
- 提供系统身份验证应用锁、后台预览隐藏和打开应用时的备份提醒。

## 数据说明

- 应用不自动上传数据，不提供托管账号或云服务。可手动将加密备份同步到用户自己的 WebDAV 服务器；关于页面中的链接由系统浏览器打开。
- JSON 与 CSV 为明文文件；需要密码保护时请选择加密备份。备份密码不保存，忘记后无法恢复加密文件。
- 完整 JSON v10 备份包含账单、分类、回收站、周期与分期计划、独立月预算、主币种、分类标签模板、保存的搜索条件、头像、昵称及外观和体验配置，兼容v1–v9旧备份；应用锁等设备安全设置保留在本机。
- 子集导出或关闭“完整备份”只包含所选账单及分类，不包含回收站、周期与分期计划、预算和标签模板。完整恢复会替换这些数据；旧备份中没有的回收站/周期或分期计划/预算/标签模板会清空，未包含主币种时恢复为CNY，导入前会说明范围。
- 单次导入文件上限为 **16 MiB**，最多 **100,000 笔账单（完整备份含回收站）、5,000 个分类、1,000 个周期规则、1,000 个分期计划**。含大量票据时可缩小导出范围，或在 CSV 中排除票据列。
- 开启后台预览隐藏会同时禁止系统截图；身份验证、模糊效果和触觉表现取决于系统与设备支持。
- 运行日志仅保留最近 100 条操作结果，不记录账单内容，不自动上传。

## WebDAV 同步与系统兼容

“我的 → 数据管理 → 同步”支持手动 WebDAV 加密备份：

1. 填写已存在的 **HTTPS 文件夹地址**、用户名与密码（可用服务商的应用密码），可测试连接，也可直接点击上传或下载，连接配置会自动加密保存。
2. 点击上传后，在弹窗输入独立的备份密码（8–128 位），在该文件夹创建独立的历史备份文件 `ledger-backup-时间戳-随机标识.qlb`，每次上传保留新文件。
3. 点击下载查看远端历史，选择备份并输入对应密码，校验并预览账单数量后确认恢复。恢复将覆盖本地账单、分类、票据和个人设置，不进行自动合并。

右上角“？”可查看同步说明。账号通过 Android Keystore 加密保存在本机，不进入导出或日志；备份密码不保存。恢复前保留本地数据的加密副本，可在同步页导出，再通过本地数据导入。新文件使用条件创建；历史选择恢复及删除使用 ETag 校验。可选择保留最近5/10/20份或不限，上传前会确认清理规则，仅清理青鸾生成的历史文件。旧版 `ledger-backup.qlb` 可单独恢复，自动清理不会删除它。历史列表要求服务器支持 PROPFIND，其他操作需 HEAD、GET、PUT、DELETE 和条件请求；缺少有效 ETag 时拒绝相关破坏性操作。列表最多读取1000个响应、1MiB，超过限制会拒绝清理。仅支持 HTTPS，不跟随重定向，不接受无效证书。没有后台同步或定时上传。

图标同时提供带透明圆角的兼容资源与自适应资源；启动页使用独立圆角图标。选图、身份验证与窗口模糊提供系统能力回退。APK兼容容器的具体行为仍取决于系统实现，本项目未声称完成鸿蒙真机验证。

## 从源码构建

### 环境要求

- JDK 17
- Android SDK Platform 35
- Android SDK Build Tools 35.0.0
- Android Studio，或可运行 Gradle Wrapper 的命令行环境

### 构建步骤

1. 克隆仓库：

   ```bash
   git clone https://github.com/wangshiyulin/qingluan-ledger.git
   cd qingluan-ledger
   ```

2. 使用 Android Studio 打开项目并完成 Gradle Sync。Android Studio 会生成本机的 `local.properties`；命令行构建也可通过 `ANDROID_HOME` 指定 SDK 路径。

3. 构建 Debug APK。

   **macOS / Linux：**

   ```bash
   chmod +x gradlew
   ./gradlew assembleDebug
   ```

   **Windows PowerShell：**

   ```powershell
   .\gradlew.bat assembleDebug
   ```

输出文件：`app/build/outputs/apk/debug/ledger-v1.1.0.apk`。

发行版启用 R8 代码优化与资源裁剪，可使用 `./gradlew assembleRelease` 构建并配置自己的发布签名。

首次构建需要联网下载构建工具及依赖；应用联网权限用于手动 WebDAV 同步。正式发布请使用自己的发布签名，并妥善保存签名文件；不同签名的安装包无法直接覆盖安装。

```text
app/
├── src/main/          应用代码、资源与第三方许可
├── src/test/          单元测试与 JVM 界面测试
├── src/androidTest/   设备测试
└── schemas/           Room 数据库结构记录
gradle/wrapper/        Gradle Wrapper
gradlew                macOS / Linux 构建入口
gradlew.bat            Windows 构建入口
```
