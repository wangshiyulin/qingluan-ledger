# 1.4.0 样式与切换调整

- 全部日期选择改为跟随 Compose Material 3 主题的日历弹窗；取消旧平台青绿/白色日期弹窗，时间也统一为 Material 输入弹窗。日期按 UTC date-only 传递，避免本地时区造成选中日期偏移。
- 页面进入、退出及返回转场均为 None。点击目标与导航器实时目的地比较，修复同一帧内 A→B→A 第二次点击被旧 route 快照忽略的问题。
- 底栏只含明细、洞察、设置；记账改为右下角悬浮按钮。底栏为四周留白、圆角液态材质，使用 Haze 背景模糊、半透明着色、细高光边缘和快速回弹。API26–30 使用库的稳定材质降级。
- 账单与设置卡片增加轻微按压回弹；图表切换仅为 100ms 局部动画。导航切换不等待这些动画。Compose 动画遵循系统动画缩放设置。
- 内容底部为悬浮按钮预留滚动空间；日历、分类、数据设置二级页面不显示底栏和记账悬浮按钮。
- 10 天以内显示所有每日等距刻度；更长区间使用固定步长取刻度，不再把不同日期间隔显示成相同槽位。图表点保持实际索引坐标。
- 圆环模式下切换按钮显示列表图标，列表模式下显示圆环图标。
- 启动页背景深色、透明叶片图标，无原深绿方块；图标放大 20%，使用自适应圆角应用图标。Android12+ 显式配置启动屏颜色和图标，移除额外退出动画；低版本使用对应深色预览背景。

验证命令 testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug 成功。33 项测试通过（业务8、备份7、Room3、Android9/14/16各五个UI场景共15）。新增测试暂停自动动画时钟，验证连续导航在64ms模拟帧推进后只保留目标页面；这不是一加真机耗时基准。新版日期选择与悬浮按钮测试通过，仪器测试APK编译成功。

APK签名、16KB ZIP对齐检查通过。包名和签名不变，versionCode6/versionName1.4.0，Room schema1，可覆盖安装。

真实GPU液态材质观感、系统启动屏与一加实机帧率仍需设备验证；未声称已完成实机截图或性能验收。
