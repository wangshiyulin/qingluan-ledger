# 1.0.4（104）

## 修改

- 个性化拆为独立圆角卡片，间隔 8dp；修复组合卡片切角。字体仅保留字号；删除材质开关，材质始终启用。清理对应旧偏好和字形分支。
- 记账按钮由 56dp 放大至 64dp，图标 28dp。
- 主页面滚动内容允许经过底栏后方，列表底部保留安全空间；底栏采用 24dp 背景模糊、半透明底色与边缘高光。此前底栏下方主要为避让后的纯色背景，因此模糊很弱。弹窗背景模糊依赖 Android/厂商支持；此实现是磨砂透明材质，不是物理光学折射。
- 导入选择 JSON 或 CSV。JSON 完整恢复，格式升级为 v4，兼容 v1/v2/v3；v3 中已移除的字形和材质偏好忽略。
- CSV 兼容应用新旧导出表头，正确处理引号、逗号、换行、不同币种精度；事务追加、补充缺失分类。按相同记录出现次数识别重复，保留同秒重复记账；无效数据拒绝整次导入。
- CSV 日期改为文本导出。截图中的 #### 通常由表格日期列太窄造成，并非日期缺失；CSV 无列宽元数据，个别阅读器仍需手动加宽 A 列。

## 必要验证

仅执行 6 个针对性用例：CSV 往返/重复导入、旧格式与无效数据、金额溢出回滚、完整 JSON、旧 JSON 兼容、个性化/格式选择/按钮尺寸。全部通过。APK 构建成功。未执行全量测试、全量审查或真机/低端设备测试；模糊观感仍取决于设备与背景内容。
