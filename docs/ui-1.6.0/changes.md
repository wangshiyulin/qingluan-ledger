# 1.6.0

## 本次修改

- 共用日期弹窗整体缩小约 10%，保留 Material 3 主题、字体缩放和日期语义。
- 年份网格由四列改为三列，年份单行显示，月份选择的年范围限制在 1900–2100。
- 币种选择只保留在记账页。明细显示全部币种的交易与分币种汇总；洞察按币种自动分组，禁止混合货币合计。
- 删除账单日期旁的重复每日收入/支出汇总。
- 洞察更多菜单仅保留日历与年度报告；移除日、周、自选入口与相关统计分支。
- 设置顶部新增纯本地头像、昵称及天数/笔数/结余。相册使用系统照片选择器，拍照交给系统相机，无网络、相机或全库存储权限。
- 头像按需解码、裁剪与方向校正，保存为 512px JPEG；导入失败保留旧图，并发导入串行写入；拍照只授予特定缓存目录的临时 URI 权限。
- 设置页可滚动，底部留出悬浮按钮空间。

## 检查与谨慎清理

检查了导航、过滤、金额和币种精度、分类引用、数据库迁移、备份恢复、外部图片与相机回调、设置持久化及权限。移除不再使用的 PageTitle、Comparison、DateSpan.of 日/周计算、旧比较周期帮助函数和全局币种切换回调。保留日期范围筛选与 JSON 校验、分类迁移、Room v1→v2 迁移等仍使用的逻辑，没有清除数据库或删除历史兼容代码。

这些是代码检查和少量针对性回归，不代表已完成全部设备兼容性验证。

## 交付与已知范围

- 新版采用原有签名，数据库仍为 v2，无新增数据库迁移需求。
- 头像和昵称不包含在账单 JSON 备份中。
- 没有连接实体手机；外部相册、厂商相机、GPU 模糊及帧率仍需实机核对。
- 为减少验证耗时，本次不重跑完整 API 测试矩阵或完整 Lint；构建可能显示既有 Material 图标弃用提示。
