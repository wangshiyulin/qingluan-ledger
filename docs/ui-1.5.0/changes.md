# 1.5.0

## 界面

- 明细顶栏：青鸾品牌、当前币种、搜索和筛选；搜索点击后展开为胶囊输入框。
- 左侧年份与月份分层，直接打开月份网格；收入、支出与结余同排，去除装饰性正负号。
- 洞察月份/年份直接网格选择；全部视图中选择月份即进入该月，避免选择日期后不生效。
- 年统计显示月均，全部统计显示单笔平均；其他周期为日均。移除概览和对比菜单。
- 日历日期与每日数值按列居中。底栏缩小为 58dp，主页面仍即时切换。

## 个性化

设置新增独立二级页，三个开关分别持久化：灵动效果（搜索缩放、按压回弹、图表与记账弹层动效）、触觉反馈（导航、分类、键盘、保存、拖动）、液态材质（底栏和弹窗背景模糊）。关闭动效使用直接出现的记账弹层；关闭液态材质使用实色表面。系统动画时长继续影响 Compose 动画。Android 12 以下模糊按 Haze/系统能力降级。

## 多币种与升级

- 内置 SIX 发布的有效 ISO 4217 币种表（2026-09-17，178 个代码），包含地区货币及基金、贵金属、测试代码，无网络请求。
- 名称优先系统本地化，系统不支持的代码显示官方英文名。
- 整数最小货币单位存储，支持零、二、三、四位精度；ISO 无指定精度的特殊代码使用两位。
- 记账页切换币种不会自动换算；若原输入不符合新币种精度，则清空金额重新输入。
- 明细和洞察按当前币种单独展示，不进行汇率换算或跨币种合计。
- Room 1→2 加字段，旧交易原金额保留、币种 CNY。备份 v2 记录每笔币种，兼容 v1 人民币备份，全部校验后事务替换。
