# 1.0.0 初始发布版

本次按用户要求将对外版本设为 1.0.0；此前 1.x 为开发迭代记录。内部 versionCode 继续递增为 11，避免 Android 将覆盖安装识别为降级；数据库继续使用已有 v2，不清空历史数据。

## 本次调整

- 左滑超过阈值后松手，直接弹出删除确认；未达到阈值时回弹，不弹窗、不删除。
- 滑动区域只显示垃圾桶图标，不再显示“删除”文字。确认、取消、系统返回或点击弹窗外部后，账单行正确复位；确认前账单不会被删除。
- 筛选弹窗使用明确的响应式宽度；所有共用日历弹窗宽度与筛选分类网格的三列总宽度一致，日历内容和高度按同一比例缩放。
- 显示版本号 1.0.0，保留原签名、包名、功能与数据兼容性。

## 验证范围

仅验证左滑阈值、取消/确认删除和日历宽度对齐两个相关界面场景，使用 Android 16 的 Robolectric 环境。未重跑完整回归或完整 Lint，未连接实体手机，不据此声明厂商设备的实际显示效果和帧率已经验证。

## 最终结果

- `assembleDebug` 成功，对外版本 1.0.0 / versionCode 11。
- 两项 Android 16 Robolectric 界面回归通过：短滑不触发、长滑松手确认、取消复位和确认删除；日历外宽与分类三列区域宽度对齐、选择日期和应用筛选。
- 原签名、APK v2 签名与 16KB ZIP 对齐校验通过。
