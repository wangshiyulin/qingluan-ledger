# 1.7.0

## 本次修改

- 明细账单点击直接进入编辑表单，移除原详情选择弹窗。
- 左滑露出删除按钮，同一时间只展开一条；点击删除后保留简短确认，整条滑动不会直接删除。提供“删除账单”辅助功能操作。
- 分类长按后图标浮起并跟随手指，自由跨行移动，其他分类实时让位；边缘自动滚动，松手保存排序，取消手势恢复原顺序。
- 长按后在初始事件阶段处理拖动并暂停网格手动滚动，避免滚动抢走手势；坐标包含网格内容内边距，避免浮动图标偏移。
- 分类图标从 12 个扩展为 40 个。旧键和顺序保留，数据库和现有备份不变；新增图标通过备份 v2 保存。包含新增图标的备份应在本版或更新版中恢复。
- 设置主页只保留分类管理、个性化、本地数据；外观模式置于个性化，通过主题单选弹窗切换，原主题偏好继续有效。
- 设置图标使用统一的 Material 线性图标与柔和圆角底板。功能图标属于 Apache-2.0 开源 AndroidX Material Icons，许可证已随源码及 APK 附带，见 THIRD_PARTY_NOTICES.md。
- 清理旧外观页面路由、已废弃的账单详情弹窗、未使用的 onAdd 参数和 withTransactionCompat 函数；保留分类迁移、历史币种/备份校验。

## 验证范围

本次只运行与变更直接相关的少量回归，不重跑完整 Lint 或所有系统版本矩阵。没有连接实体手机，不能据 JVM 模拟结果断言一加设备的实际拖动手感、GPU 模糊和帧率。

数据库保持 v2，无清库或破坏性迁移。应用继续无网络权限，APK 使用原 Debug 签名。
