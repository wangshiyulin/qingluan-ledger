# 体验配置与本地数据 Implementation Plan

Goal: 完成截图及用户选择的六组体验功能，保持离线、兼容旧数据。
Architecture: Compose 页面，DataStore JSON 体验配置，Room 无损迁移，事务批量操作；范围规则复用导入导出，JSON 完整备份兼容旧版。只做两次批次检测和一次最终必要检测/人工代码审查。
Tech Stack: Kotlin/Compose/Room/DataStore，Android 系统身份认证与标准 Java 加密，无新依赖。

## 第一批
- [x] 个人资料：右上角重置，清空昵称/头像；选图先进入圆形裁剪，可拖动缩放后保存。
- [x] 操作反馈：动画/触觉强度与场景、删除撤销；保持页面立即切换。
- [x] 列表显示：密度、时间/备注显隐、金额遮罩；必要设置持久化并纳入备份。
- [x] 批次检测：构建和头像/配置必要用例。

## 第二批
- [x] 统计偏好：默认周期/类型/图表、记住筛选；用保存偏好初始化并明确更新。
- [x] 导入导出：JSON/CSV/加密 JSON，全部/当前筛选/指定日期范围，预览数量/币种/错误，追加或替换范围、重复跳过或保留，CSV 可选备注/标签/图片列与文件名，SAF 保存位置。
