# 1.0.2 代码与依赖检查

## 检查范围

检查金额存储与精度、交易增删改查、类型/分类/日期/关键词筛选、跨币种统计隔离、趋势与日历/年度报告、分类删除与迁移排序、Room v1→v2 升级、JSON 导入校验及事务替换、头像 URI/文件处理、偏好与协程生命周期、导航和触摸事件、Manifest 权限、资源与 Gradle 依赖。检查不意味着对任意设备和数据规模作无缺陷保证。

## 截图修改

- 收入和支出的分类网格均删除“全部分类”入口。未选分类时不限制分类；再次点击同一分类可取消选择，重置清除分类限制。这一有效业务状态不作为死代码删除。
- 日历、年度报告各自使用带标题、周期/币种副标题、分隔线和圆角背景的独立区域。
- 本地数据操作改名为导出、导入，保留 JSON 版本校验、16MiB 读取限制与覆盖确认。

## 已修正与清理

1. 日历原先始终统计支出，现随收入/支出选项切换金额和颜色。
2. 年报、日历、币种分组改为复用分组结果，避免每个日期、每个月和每个币种重复扫描整个列表。
3. 删除“全部分类”组件及收入/支出混合分类名称后缀逻辑；移除无意义的周期分支与重复分组计算。保留重置、未选择分类、数据库迁移、分类引用和备份字段等仍有用途的逻辑。
4. 编辑不存在的账单会明确失败，避免 @Update 零行更新被当作成功。
5. 导入分类引用校验使用按 ID 的索引，避免最多十万条账单乘五千个分类的重复查找；先验 ID 唯一性再建立映射。
6. 协程取消异常继续传播，避免取消被普通错误处理吞掉。
7. 新安装的默认收入分类匹配工资、退款等语义图标；已有分类及用户图标不覆盖。
8. 文件选择器返回空流时提供明确错误；头像显示移除不必要的非空断言，异步加载改为明确的状态和 LaunchedEffect，消除 Lint 的状态生产告警。
9. 系统 EXIF 解析器改用官方 AndroidX ExifInterface 1.4.1，避免依赖旧 Android 系统实现。保留有界图片解码、头像原子替换与旧图保护。
10. 移除 `debugImplementation("androidx.compose.ui:ui-test-manifest")`：现有测试全部直接使用 MainActivity，不需要库中的占位测试 Activity；设备测试包和相关 JVM 界面测试仍构建/运行成功。
11. 其他运行依赖均有实际用途（Compose、Navigation、Lifecycle、Room、DataStore、Haze、图标）；JUnit、Robolectric、JSON 与 Compose/Android 测试库是测试依赖，不作为无用框架删除。
12. 合并最低系统已覆盖的 mipmap-anydpi-v26 资源目录为 mipmap-anydpi，补全 Android 12+ 云备份与设备迁移排除规则，保留纯本地设计及文件选择器手动导出/导入。

数据库仍为 v2，备份仍为 v2 并兼容 v1；没有清库或删除历史字段。没有新增账号、网络或追踪服务。

## 验证及实际限制

本次运行全部数据层/头像测试和一个 Android 16 截图组合场景，不重跑所有旧界面在每个 API 上的矩阵。编译设备测试 APK 不代表运行过真实设备测试。大数据性能、厂商相机和键盘、跨时区实时变化、大字号及中低端 GPU 仍需实体设备验证。

Lint 剩余 14 项提醒：13 项为依赖可升级提示，1 项为可选 monochrome 桌面图标缺失。未为了消除升级提示而批量升级已锁定组件，也未为主题图标改动用户品牌图案。

最终结果：32 项通过、0 失败、0 跳过；assembleDebug、assembleDebugAndroidTest 和 lintDebug 成功。Lint 0 错误、14 提醒。APK 签名及 16KB ZIP 对齐通过。APK SHA-256：`5f0313eb091c4e66030244583a465793a0f667f1000ffcd926c2ea75438a682a`。

交付 APK 重新封装，清除增量打包遗留的无引用空洞；复核所有有效 ZIP 条目内容完全相同，体积由约 22.5MB 降至约 17.8MB。这不改变代码、资源、签名身份或测试结论。
