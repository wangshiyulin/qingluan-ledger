# 1.0.3

## 新功能

- 明细仍使用本地 Room Flow，不引入数据库分页或 Paging 依赖；列表先显示 50 条，接近底部时自动继续显示，每批最多 50 条，无下一页按钮。月份/类型/分类/搜索变化会重置显示范围，顶部统计始终使用完整筛选结果。
- 完整 JSON 备份版本为 3，包含全部账单、分类、头像、昵称、外观模式、配色主题、字体和个性化开关。旧版 v1/v2 备份可导入，旧备份只替换账单/分类，保留当前个人资料与设置。
- 完整备份保留 16MiB 文件和原有记录数限制；头像只接受有界有效图片。导入在修改前完整校验，使用私有恢复日志、Room 事务和失败补偿，启动及后续数据导入/导出前恢复中断操作。文件操作用 AtomicFile，导入、保存与偏好写入串行执行；关闭数据库会等待这些操作退出。
- CSV 账单导出包含本地日期/时间、类型、分类、币种、原精度金额及备注；UTF-8 BOM、CRLF，正确转义引号、逗号和换行，并防止备注/分类作为电子表格公式执行。CSV 仅导出，不作为恢复格式。
- 个性化增加“字体”：跟随系统、小、大、特大，以及系统、衬线、等宽字形。字号以系统字号为基础相对缩放，图表刻度也使用相应字号/字形。
- 个性化增加“主题”：系统配色（Android 12+ 动态色）、青竹、海蓝、暮紫、暖杏、蔷薇；增加纯黑深色开关。较旧系统的系统配色使用稳定的青竹降级配色。
- 新账单默认在保存时读取系统当前时间，打开输入面板后日期/时间会跟随设备时钟更新。保留手动选择日期和时间、日历补记；仅编辑金额/备注时保留原账单时间及秒数。

数据库版本仍为 2，无新增数据库迁移或清库。版本名 1.0.3，versionCode 103，签名延续上一版。备份为可读的本地明文 JSON，不自动上传。
