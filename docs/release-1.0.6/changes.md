## 按用户要求分批实现

第一批三项：个人资料右上角重置昵称/头像，选图圆形预览可拖动/缩放；操作反馈强度、场景与删除撤销；列表密度、时间/备注显隐和全界面金额遮罩。完成后构建和一个配置/裁剪必要用例通过。

第二批三项：统计周期/类型/列表圆环默认项与筛选记忆；范围导入导出；数据保护与批量账单管理。完成后构建和两个范围/批量/加密必要用例通过。

### 数据与账单

- JSON、CSV、密码加密 JSON（.qlb）均能导入。导入先解析校验和预览，错误 CSV 提示行号；可按日期闭区间、收支、币种筛选；可追加或替换所选范围，重复记录可跳过或保留。完整 JSON 另有显式覆盖本地数据模式，覆盖先确认。
- 导出支持全部、最近明细筛选、指定日期、长按多选账单，可进一步筛选币种和收支。可选文件名与系统保存位置；CSV 日期/时间/类型/分类/币种/金额为固定基础列，备注/标签/票据可选，所有列组合可再导入。
- 完整备份含个人资料和体验配置，子集 JSON 仅含账单及分类。JSON v5 兼容 v1–v4；数据库 v3 保留 1→2→3 无损迁移，新增标签和压缩票据。
- 长按明细进入多选，支持全选、批量备注/标签/同类型分类、删除和所选导出。批量写入事务处理；删除后可撤销。单笔编辑提供标签、常用备注与压缩票据图片。
- 票据随 JSON 和可选 CSV 票据列导出；图片经有界解码、方向处理并压缩为最长边512的JPEG。备份/导入文件上限16MiB，超过时需缩小范围或CSV排除票据。

### 数据保护

- .qlb：PBKDF2-HMAC-SHA256 210000次、随机16字节盐、AES-256-GCM、随机12字节IV及认证附加数据。密码不持久化，不能找回；普通 JSON/CSV 仍为明文。
- 应用锁：Android11+ 系统强生物识别或设备凭据，旧系统使用锁屏凭据；启停需验证，离开后立即/1分钟/5分钟可选。无系统锁屏时不能启用。
- 隐藏后台预览使用 FLAG_SECURE，同时禁用系统截图。安全开关保留本机，不由备份覆盖。
- 备份提醒每7/30天，在打开应用时检查，可推迟一天；完整 JSON/加密备份保存成功后重新计时。没有通知权限、后台上传或自动云备份。
