# 后续功能状态

1.0.0 已包含的功能：个人资料重置与裁剪；反馈强度/场景和删除撤销；列表显示设置；统计偏好；范围导入导出、预览、错误行与重复策略；加密备份/备份提醒/应用锁/后台预览隐藏；多选批量管理、标签、常用备注、票据图片。详见 README.md。

仍可继续：

- 默认记账币种、收支、分类与最近分类优先。
- 连续记账、自动草稿、复制上笔、金额计算器。
- 按钮位置与尺寸、收支配色、周起始日、12/24小时制。
- 外部CSV列映射、自动备份目录及保留份数；目前支持本应用导出的列格式。
- 预算、订阅提醒、周期账单、多账本、账户与转账。
- 小组件、桌面快捷记账与无障碍专项。
- 正式发布签名及GitHub Releases版本管理。

建议下一轮优先默认记账偏好、连续记账/草稿和金额计算器。继续保持滚动渐进显示，不引入数据库分页或低端设备测试。
