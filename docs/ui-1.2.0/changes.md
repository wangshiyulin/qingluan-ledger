## 下载方式

此前 /workspace/... 和 sandbox:/workspace/... 是 Codex 云工作区文件引用，客户端尝试调用文件查看/导出服务，并非公共互联网下载地址。

现使用用户已授权的 tmpfiles.org 临时文件托管：POST /api/v1/upload 上传 APK；响应返回展示页地址，读取其中 class=download 的带时效签名 /dl/... URL。实际下载一遍，确认 Content-Disposition: attachment、APK MIME 类型与原文件 SHA-256 完全一致，再提供直链。临时服务约一小时过期。与上一次成功的 HTTPS 直链使用相同方法。APK 内未加入该服务或网络权限。

### 下载有效期更正

2026-11-09 发现：tmpfiles 文件保留约一小时，但页面生成的签名直链只约五分钟有效。旧直链过期后 302 回展示页，HTTP 200 返回 2837 字节 text/html；若另存为 APK，会提示安装包损坏。之前聊天中将一小时描述为直链有效期不准确。

本地 APK 及初始回下载副本 SHA-256 一致；apksigner v2 验证、ZIP CRC 与 zipalign 16KB 对齐验证均通过。已重新上传同一已验证 APK并生成新签名链接，后续必须告知五分钟有效期并提供展示页作为备用，不可把展示页或过期直链的 HTML 当成 APK。
