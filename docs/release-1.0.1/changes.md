# 1.0.1

## 本次修改

- 明细收支筛选删除“全部”类型及 ALL 分支，只保留支出、收入，默认和重置为支出；分类列表仅呈现当前类型。保留“全部分类”这一独立分类选项。
- 顶部金额概览仍按日期、分类与关键词范围分别计算收入、支出和结余，避免默认支出列表导致已有收入显示为零。
- 搜索框支持点击外部空白处退出，同时清空关键词、清除输入焦点和隐藏键盘。保留关闭按钮；点击筛选按钮也退出搜索。
- 空白点击监听不消耗触摸事件；点击搜索框或其他按钮、滚动列表不会被误当作退出操作。
- 版本名 1.0.1，内部 versionCode 使用整数 101 对应该版本。Android 的 versionCode 不接受 1.0.1 这种带点字符串。

数据库和备份版本不变，包名和签名保持不变。源码包不包含私有签名或本机配置。

## 验证范围

仅运行 Android 16 Robolectric 下的相关界面回归，不重复完整 Lint 或完整系统矩阵；没有连接实体手机。真机键盘与厂商系统反馈仍需要安装后核对。
