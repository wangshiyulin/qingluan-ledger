# 1.3.0 调整与验证

- 筛选全部/支出/收入间距增加到 10dp，分类选项改三列滚动网格；同名收支分类在全部模式下以入/出区分。
- 删除分类迁移目标改为两列滚动单选网格，保留事务迁移和删除校验。
- 选分类后的金额页移除重复分类选择行和清空图标；备注直接位于金额下方，不再弹出备注输入框。
- 数字键盘为 7–9、4–6、1–3、点/0/退格；日期与时间按钮放右侧，完成键在右下，退格长按可清空。收入/支出头部按钮可回分类网格，保留草稿。

- 分类占比改为彩色圆环，中心总计，底部两列颜色/分类/占比图例。点击图例可查看该分类账单；圆环模式隐藏重复排行行。
